# Démarches Automobile

Site vitrine statique en français, responsive, pour présenter un service indépendant d'accompagnement aux démarches automobiles.

## Fichiers
- `index.html` : page d'accueil et services
- `styles.css` : mise en page et design responsive
- `script.js` : menu mobile et année automatique
- `mentions-legales.html` : modèle à compléter avant publication

## Publier gratuitement avec GitHub Pages
1. Créez/connectez-vous à un compte sur https://github.com/
2. Créez un dépôt public, par exemple `demarches-automobile`.
3. Téléversez les quatre fichiers du site à la racine du dépôt.
4. Ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**, sélectionnez `main` et `/ (root)`, puis **Save**.
6. Attendez la fin du déploiement. GitHub affichera l'adresse publique du site dans la section Pages.
